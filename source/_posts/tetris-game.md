## Tetris 俄罗斯方块网页游戏

经典俄罗斯方块网页版！永恒的益智游戏，考验你的反应和策略。

### 游戏特色

- 经典俄罗斯方块玩法
- 7种经典方块形状
- 等级系统，速度递增
- 下一个方块预览
- 本地存储最高分数

### 操作说明

| 按键 | 功能 |
|------|------|
| ← → | 左右移动 |
| ↑ | 旋转方块 |
| ↓ | 加速下落 |
| 空格 | 直接落下 |
| P | 暂停游戏 |

### 游戏规则

1. 方块从顶部自动下落
2. 填满一行即可消除得分
3. 同时消除多行获得更高分数
4. 方块堆到顶部游戏结束
5. 每消除10行升一级，速度加快
