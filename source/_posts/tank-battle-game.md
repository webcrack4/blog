## Tank Battle 坦克大战网页游戏

经典坦克大战网页版！重温童年回忆，使用 HTML5 Canvas 和原生 JavaScript 开发。

### 游戏特色

- 经典坦克大战玩法
- 多关卡系统，难度递增
- 智能敌人AI
- 可破坏的砖墙
- 保护基地不被摧毁

### 操作说明

| 按键 | 功能 |
|------|------|
| W / ↑ | 向上移动 |
| S / ↓ | 向下移动 |
| A / ← | 向左移动 |
| D / → | 向右移动 |
| 空格 / J | 发射子弹 |
| R | 重新开始 |

### 游戏目标

1. 消灭敌方坦克获得分数
2. 保护你的基地不被摧毁
3. 达到目标分数进入下一关
4. 注意躲避敌方子弹
